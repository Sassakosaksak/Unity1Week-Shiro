# Unity-1Week-Shiro

2D正面構図のプロトタイプです。

このプロジェクトは2D前提です。ゲーム本体はSpriteRendererとVector2で動き、3D物理や3Dモデルは使いません。

## いま入っているもの

- 画面正面の城から砲弾が飛んでくる
- 城から撃ち上がった砲弾が画面上部の外へ消え、そのまま手前へ落ちてくる
- 大量の砲弾が短いバーストで降ってくる
- マウス移動で剣の軌道と勢いを作る操作
- 剣の長軸移動では回転しにくく、横方向移動で回転する慣性挙動
- 剣と砲弾のゲーム側反射判定
- 低速では砲弾に押し負け、中速では低ダメージ反射、高速では高ダメージ反射
- 高速反射時の短いヒットストップ
- 反射後でも手前へ落としてしまうと自陣ダメージ
- 敵城の砲撃、城HP、防衛ライン、勝敗
- 魔力ゲージと満タン時の簡易魔力砲

## 起動方法

Unityでこのフォルダを開き、任意の空シーンでPlayしてください。

シーン内に何も置いていなくても、`GameBootstrap` が自動でカメラ、剣、城、砲台、HUDを生成します。

## 操作

- マウス移動: 剣の軌道と勢いを作る
- Space: 魔力ゲージ満タン時に魔力砲
- R: 勝敗後にリスタート

通常の攻撃手段は砲弾の反射だけです。剣先で速く振り抜くほど、砲弾は強く城へ返ります。
